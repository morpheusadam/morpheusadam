## About

I am Morpheus Adam (Hesam Ahmadpour). I build production web applications, and increasingly
AI-backed SaaS and automation on top of them.

- **Core work:** Laravel and PHP backends, modular architecture, OOP and REST APIs, backed by
  MySQL/MariaDB, Redis, Linux and Docker.
- **Domain:** e-commerce platforms, video and content CMS, payment gateways, and
  WordPress/WooCommerce plugins and themes.
- **AI and automation:** LLM integration (OpenAI, Anthropic Claude, Gemini), AI SaaS, chatbots,
  and n8n workflow automation.
- **Specialty:** RTL and Persian-first interfaces, and internationalised products.
